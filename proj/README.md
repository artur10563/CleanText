# CleanText

Програма для дослідження **методу виявлення некоректно розмічених україномовних текстових зразків у процесі навчання нейромереж за умов шуму в мітках**.

Метод ранжує навчальні зразки за інтегральним ризиком

```
Rᵢ = α·Cᵢ + β·Dᵢ + γ·Sᵢ,   α + β + γ = 1
Cᵢ = 1 − (1/T)·Σₜ pₜ(ỹᵢ|xᵢ)                 — середня невпевненість у наявній мітці
Dᵢ = 1 − (1/T)·Σₜ 1[argmax pₜ(·|xᵢ) = ỹᵢ]     — частота незгоди передбачення з міткою
Sᵢ = 1 − (1/k)·Σⱼ∈Nₖ(i) 1[ỹⱼ = ỹᵢ]            — неузгодженість із k семантичними сусідами
```

і порівнює його з Random, Loss, margin-подібним показником, Cleanlab OOF та абляціями R(C,D,0), R(0,0,S).

## Запуск

```bat
py -m pip install -r requirements.txt
run.bat                      :: або: py -m streamlit run app.py
```

Інтерфейс відкриється в браузері (http://localhost:8501). Перший запуск завантажує корпус і модель MiniLM з Hugging Face та кешує їх у `data/cache/`.

Без інтерфейсу (`--budgets 0.05 0.10 0.20` задає бюджети перенавчання):

```bat
py cli.py --dataset ua_news --noise semantic --rate 0.2 --preset quick
py cli.py --dataset uareviews --task intent --grid --types symmetric asymmetric semantic --rates 0.1 0.2 0.3 0.4 --seeds 13 42 77
```

## Тестування

```bat
py -m pip install -r requirements-dev.txt
py -m pytest -q                 :: швидкі unit-тести (≈10 с): шум, ознаки C/D/S, метрики, дублікати, калібрування, формули за docx
py -m pytest -q -m slow         :: наскрізні тести, схеми артефактів і сторінки UI на синтетичному корпусі (≈1,5 хв)
py -m pytest -q -m "slow or not slow"   :: усі тести
```

Тести не потребують мережі (синтетичний корпус, `tfidf_svd` + MLP). Результати запусків — у `tests/results/`.

**Калібрування ваг:** за замовчуванням ваги α, β, γ підбираються на окремій підвибірці (`calib`) з власним шумом, і поруч із «R фіксований» з'являється «R адаптивний». М'яке зважування підозрілих зразків (замість вилучення) вмикається за замовчуванням, вимкнути: `--no-weighted`. Вимкнути калібрування: `--no-calibration`; режим шуму: `--calib-mode known_type|mixed`. Повний AUM (Pleiss et al., 2020) з пороговими зразками й карта Dataset Cartography увімкнені за замовчуванням, вимкнути AUM: `--no-aum`.

## Методологічні застереження

- «Помилка» при штучному шумі означає лише навмисно змінену мітку; індикатор zᵢ використовується тільки для оцінювання.
- Margin-подібний показник — діагностична базова оцінка, а не повна процедура AUM із пороговими зразками.
- Cleanlab отримує out-of-fold ймовірності; шум вноситься лише в train.
- Жодних результатів у програмі наперед не задано: усі числа отримуються під час запуску.
- Ліцензія UAReviews — CC BY 4.0; умови UA-News слід перевірити в картці набору.

**Підказки та посібник:** біля полів введення є кнопки «?»; сторінка «Посібник» (меню «Довідка») пояснює програму без технічних термінів. Вимкнути підказки: перемикач на бічній панелі або `CLEANTEXT_HINTS=0`. Тексти — у `ui/locales/uk.py`; інша мова — новий файл `ui/locales/<код>.py` і `CLEANTEXT_LANG=<код>`.
